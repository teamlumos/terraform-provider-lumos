# lumos_app_appstore_settings (Resource)

An app's App Store settings: whether it's listed, who can request it, and what the request form asks. Keyed by the app's ID.

## Example Usage

```terraform
variable "engineering_group_id" {
  type = string
}

# Lists Okta in the App Store for one group, with two time-based access
# options and a question on the request form. Time-based access options are
# referred to by the labels your organization defines.
resource "lumos_app_appstore_settings" "okta" {
  app_id                        = lumos_app.okta.id
  in_app_store                  = true
  catalog_visibility            = "visible"
  request_instructions          = "Request the role your team uses."
  allowed_requester_group_uuids = [var.engineering_group_id]

  time_based_access = {
    options = ["1 day", "1 week"]
    default = "1 day"
  }

  custom_intake_fields = [{
    reference_key = "justification"
    field_type    = "text"
    prompt        = "Why do you need access?"
    is_required   = true
  }]
}
```

## Behavior

* **One per app.** Changing `app_id` replaces the resource: the old app is taken out of the App Store, keeping its other settings, and the new app's settings are written.
* **Unlisting:** set `in_app_store = false` to take the app out of the App Store while Terraform keeps managing its settings. Destroying the resource also unlists it, then stops managing the settings.
* **Time-based access options** are set and shown by their labels.
* **Omitted settings are left as they are.** Only the settings in the config are managed.

## Destroy behavior

Destroy takes the app out of the App Store (`in_app_store = false`). The rest of its App Store configuration stays. To stop managing the settings without unlisting the app, use a `removed` block:

```terraform
removed {
  from = lumos_app_appstore_settings.okta

  lifecycle {
    destroy = false
  }
}
```

## Import

The import ID is the app's ID. Importing works for apps Terraform doesn't manage, including apps connected in the Lumos UI.

In Terraform v1.5.0 and later, an [`import` block](https://developer.hashicorp.com/terraform/language/import) can be used:

```terraform
# The import ID is the app's ID.
import {
  to = lumos_app_appstore_settings.okta
  id = "<app id>"
}
```

The [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import) can also be used:

```shell
# The import ID is the app's ID.
terraform import lumos_app_appstore_settings.okta "<app id>"
```
