# lumos_entitlement (Resource)

An entitlement on an app: a role, license, group or permission. App Store settings show here read-only; manage them with `lumos_entitlement_appstore_settings`.

## Example Usage

```terraform
# A manual entitlement: one created in Lumos rather than synced from an
# integration. Its app can be a custom app or a connected integration.
resource "lumos_entitlement" "deploy_admin" {
  app_id = lumos_app.deploy_dashboard.id
  label  = "Admin"

  description_override             = "Full admin access to Deploy Dashboard. Ask in #deploys before requesting."
  custom_approval_message_override = "Your Deploy Dashboard admin access is approved. Ask in #deploys if you need help."
}
```

## Behavior

* **Creating** adds a manual entitlement to the app. Entitlements synced from an integration can't be created, but they can be imported, for example to manage their App Store settings.
* **Only `label` can change, and only on manual entitlements.** Renaming one synced from an integration fails, because the sync owns its label. Renaming also changes the name shown in the App Store. Changing `app_id` replaces the entitlement.
* **App Store settings** appear read-only in `appstore_settings`. They're null while the app isn't in the App Store or the entitlement has no request settings. Change them with `lumos_entitlement_appstore_settings`.

## Destroy behavior

Destroy deletes the entitlement and its App Store settings. Lumos refuses the delete, and destroy fails with the API's error, when the entitlement:

* is synced from an integration,
* is still held by anyone,
* has pending access requests, or time-based access scheduled for removal, or
* is referenced by an access policy.

To stop managing an entitlement without deleting it, use a `removed` block:

```terraform
removed {
  from = lumos_entitlement.deploy_admin

  lifecycle {
    destroy = false
  }
}
```

## Import

In Terraform v1.5.0 and later, an [`import` block](https://developer.hashicorp.com/terraform/language/import) can be used with the entitlement's ID:

```terraform
import {
  to = lumos_entitlement.deploy_admin
  id = "<entitlement id>"
}
```

The [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import) can also be used:

```shell
terraform import lumos_entitlement.deploy_admin "<entitlement id>"
```
