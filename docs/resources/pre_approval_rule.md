# lumos_pre_approval_rule (Resource)

A pre-approval rule: access requests for an app that Lumos approves without a reviewer when the requester matches the rule's condition.

## Example Usage

```terraform
# Pre-approves requests for the deploy dashboard's Viewer entitlement from
# anyone on the Platform team, for up to 30 days.
resource "lumos_pre_approval_rule" "platform_viewers" {
  app_id        = lumos_app.deploy_dashboard.id
  justification = "The Platform team reads deploy status every day."

  condition = jsonencode({
    and = [
      {
        attribute = { label = "Team", value = "identity.team" }
        equals    = { label = "Platform", value = "Platform" }
      },
      {
        attribute = { label = "Access length", value = "access_request.access_length" }
        "<="      = { label = "30 days", value = 2592000 }
      },
    ]
  })

  request_includes_entitlements = [lumos_entitlement.deploy_viewer.id]
}

# Pre-approves a request for any of the wiki's entitlements when the
# organization's pre-approval webhook approves it. A request for the wiki
# itself, with no entitlement, isn't covered.
resource "lumos_pre_approval_rule" "wiki_by_webhook" {
  app_id        = lumos_app.wiki.id
  justification = "An access service decides who can read the wiki."

  condition = jsonencode({
    attribute = { label = "Access check", value = "webhook.responses[\"<pre-approval webhook id>\"]" }
    equals    = { label = "Pre-approved", value = "PREAPPROVED" }
  })

  request_has_entitlements = true
}

# Pre-approves requests for the deploy dashboard's Admin entitlement from
# whoever is on call for the platform rotation, for up to 12 hours.
resource "lumos_pre_approval_rule" "deploy_admins_on_call" {
  app_id        = lumos_app.deploy_dashboard.id
  justification = "The on-call engineer may need to roll back a deploy."

  condition = jsonencode({
    and = [
      {
        attribute = { label = "On call", value = "identity.oncall[\"<schedule entitlement id>\"].on_call" }
        equals    = { label = "On call", value = true }
      },
      {
        attribute = { label = "Access length", value = "access_request.access_length" }
        "<="      = { label = "12 hours", value = 43200 }
      },
    ]
  })

  request_includes_entitlements = [lumos_entitlement.deploy_admin.id]
}
```

## Schema

### Required

- `app_id` (String) The ID of the app the rule applies to. For an app merged into another app, use the ID of the app it was merged into. Requires replacement if changed.
- `condition` (String) Who the rule pre-approves, and for how long they can have access, as a Lumos condition written with `jsonencode`. Give every attribute and value as `{ label, value }`, the form Lumos reads back. Parsed as JSON.
- `justification` (String) Why the rule exists, shown to requesters and reviewers.

### Optional

- `request_does_not_include_entitlements` (Set of String) IDs of the entitlements the rule doesn't cover, in lowercase. The rule covers every other entitlement and a request for the app itself.
- `request_has_entitlements` (Boolean) `true` covers a request for any of the app's entitlements. `false` covers only a request for the app itself, and is what a rule with none of the three entitlements fields set gets.
- `request_includes_entitlements` (Set of String) IDs of the entitlements the rule covers, in lowercase. The rule covers no other entitlement, and not a request for the app itself. Set at most one of `request_includes_entitlements`, `request_does_not_include_entitlements` and `request_has_entitlements`.

### Read-Only

- `id` (String) UUID of this pre-approval rule.

## Behavior

* **Conditions:** write `condition` with `jsonencode`, giving every attribute and value as `{ label, value }` as in the example: that's the form Lumos stores and reads back, so any other form shows a change on every plan. Every rule needs a condition. Besides identity attributes, a condition can check:
  * a pre-approval webhook: attribute `webhook.responses["<inline webhook id>"]` with `equals` `{ label = "Pre-approved", value = "PREAPPROVED" }`. The webhook must be a pre-approval webhook.
  * an on-call schedule: attribute `identity.oncall["<schedule entitlement id>"].on_call` with `equals` `{ label = "On call", value = true }`.

  Neither can be inside a `not`. See [building conditions in Lumos](https://docs.lumos.com/kb/life_cycle_management/building-conditions-in-lumos).
* **Which requests the rule covers:** set `request_includes_entitlements` to cover only those entitlements, `request_does_not_include_entitlements` to cover every other entitlement and a request for the app itself, or `request_has_entitlements = true` to cover any entitlement. Set at most one. With none set, the rule covers only a request for the app itself, and `request_has_entitlements` reads `false`. Removing a list from the configuration changes the rule to match.
* **Entitlement IDs** are stored in lowercase and their order doesn't matter, so write them in lowercase.
* **`app_id`** must be the ID of the app the rule is stored on. For an app that was merged into another app, use the ID of the app it was merged into: Lumos stores the rule there and reads that ID back, so any other ID fails the apply.
* **Rules created by an access policy,** for apps marked `is_preapproved` in a `lumos_access_policy`, can't be managed here: Lumos refuses to change or delete them, and they read back without a condition. Manage them through the access policy.

## Destroy behavior

Destroy deletes the rule. It doesn't revoke access already granted through it.

To stop managing a rule without deleting it, use a `removed` block:

```terraform
removed {
  from = lumos_pre_approval_rule.platform_viewers

  lifecycle {
    destroy = false
  }
}
```

## Import

A rule is imported with a JSON object holding its app's ID and its own ID. In Terraform v1.6.0 and later, an [`import` block](https://developer.hashicorp.com/terraform/language/import) can build it with `jsonencode`:

```terraform
import {
  to = lumos_pre_approval_rule.platform_viewers
  id = jsonencode({ app_id = "<app id>", id = "<pre-approval rule id>" })
}
```

The [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import) can also be used:

```shell
terraform import lumos_pre_approval_rule.platform_viewers '{"app_id": "<app id>", "id": "<pre-approval rule id>"}'
```
